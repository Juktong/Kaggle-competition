## New finding: the full pipeline is NOT bit-deterministic across runs

Comparing the SP45 output of the two full runs (same config):

```
identical = False   rmse 0.333 ft   max|d| 1.004 ft   97.1% of rows differ by >0.01 ft
```

This refines A1 (2026-07-25), which proved the **PF** is deterministic given `seed_base`. The full
pipeline also trains LightGBM/CatBoost on GPU (`device_type="gpu"`, `task_type="GPU"`), and that is not
bit-reproducible across runs. So:

- **Same-config run-to-run prediction noise ≈ 0.333 ft rmse** — a real variance source on top of the
  ~0.115 public config-variance floor from A1.
- The SP45-vs-final gap (0.556–0.678 within a run) is **larger** than this run-to-run noise, so it is a
  genuine effect rather than an artifact. Cross-run comparisons of the same stage (2.581 vs 2.703, spread
  0.12) should not be over-read.
